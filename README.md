 - Run (Left Shift),

- AimVisble (Right Mouse Button),


- Fire(Left Mouse Button),


- Roll (Q),


- LaunchGranade (G),


- PauseMenu (P),


- Rotation & MoveCam (Mouse),


- Scroll (Mouse Wheel)
