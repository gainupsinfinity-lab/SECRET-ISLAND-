# SECRET-ISLAND-
Progetto Corso Di Programmazione Avanzata - Game 
Utilizzo Tipo :UNREAL 5.1,
Tasti con Keyboard,
Input di riferimento :
WASD (movimento),
Run (Left Shift),
Jump(Space Bar),
Crouch(Left Ctrl),
Gun (Right Mouse Button),
Interact(E),
Incentory(I),
AimVisble(Right Mouse Button),
Fire(Left Mouse Button),
Roll(Q),
LaunchGranade(G),
PauseMenu(P),
Rotaion & MoveCam(Mouse),
Scroll(Mouse Wheel)
NB.E' stato inserito come test U per usare l'obj. Tale  non è da utilizzarsi poichè prende il primo oggetto utile nella scorrimento degli oggetti presenti (non implementato).
Utilizzare il Mouse per la selezione degli oggetti nell'Inventory.
